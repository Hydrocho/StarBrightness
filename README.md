# 별빛 탐사실

## 03 · 별의 거리 퀴즈

- 연습 모드: 무작위 별 A~E를 선택해 지구 쪽 또는 바깥쪽으로 드래그하거나 거리 슬라이더(3~30 pc)를 조절합니다. 절대등급은 유지되며 거리와 겉보기등급이 즉시 바뀝니다. ‘10 pc에 놓기’로 두 등급이 같아지는 것을 확인할 수 있습니다. 모든 별은 지구 오른쪽으로 뻗은 같은 직선 위에 배치됩니다. 가로 위치는 거리에 비례하며, 0~30 pc 눈금과 10 pc 기준선을 표시합니다. 같은 거리는 같은 위치에 놓이며 A~E 버튼으로 겹친 별도 선택할 수 있습니다. 너비 1200px 이상에서는 표·거리 조절기와 시뮬레이션을 좌우 2:3 비율로 배치합니다. 거리축은 시뮬레이션 오른쪽 끝 가까이까지 사용하며, 별의 드래그 영역은 44px로 확대했습니다. 끝부분의 등급 카드는 화면 안쪽으로 조정해 잘리지 않게 표시합니다. 표 아래 별 A~E 버튼으로 가까이 모인 별도 선택할 수 있습니다. 10 pc 기준선을 민트색으로 강조합니다. 별을 클릭·터치하거나 A~E 선택 버튼을 누르면 선택한 별 오른쪽에만 겉보기등급(노랑)과 절대등급(파랑)을 표시합니다. 처음에는 별 옆 등급을 숨깁니다. 시험 결과와 기록의 지도에서도 별을 눌러 확인할 수 있습니다. 절대등급 숫자가 작을수록 별의 중심과 빛무리를 더 밝게 표현하며, 거리 이동과 선택 테두리는 이 밝기를 바꾸지 않습니다. 화면에서는 넓은 광도 범위를 압축한 학습용 표현을 사용합니다. 작은 화면에서는 지도를 좌우로 스크롤할 수 있습니다. 별에 초점을 두고 방향키(0.1 pc, Shift 1 pc)로 거리를 조절할 수 있습니다. 시험 결과와 기록에서도 같은 직선 거리 지도를 표시합니다.
- 시험 모드: 새 별 5개로 등급 차이 5문항, 조건별 복수 선택 7문항, 거리순 배열 1문항을 풉니다. 제한 시간은 없고, 제출 전에 정답과 거리 그림을 숨깁니다. 각 문항 동일 배점이며 모두 맞히면 1,000점입니다. 복수 선택은 해당 별을 모두 골라야 정답입니다.
- 제출 결과에는 내 답·정답·풀이와 실제 거리 그림을 표시합니다. ‘오늘의 기록’의 세 번째 항목에서 당일 최근 5개 시험의 점수와 상세 결과를 다시 확인할 수 있습니다. 점수와 관계없이 가장 최근에 종료한 시험부터 표시합니다. 시험 모드 진입 또는 새 문제 생성 시 시작 시각을, 제출 시 종료 시각을 초 단위로 저장해 목록과 상세 결과에 표시합니다. 예전 기록에 시작 시각이 없으면 기록 없음으로 표시합니다. 동일 점수도 별도 기록하며 기존 두 게임의 기록과 별도로 보관합니다. 날짜는 기기 현지 날짜를 사용합니다. 저장소를 사용할 수 없으면 페이지가 열려 있는 동안만 기록을 유지합니다.
- 연습/시험 전환과 ‘새 랜덤 별 5개’는 새 문제를 생성하고 작성 중인 답을 초기화합니다. 상단의 다른 기능으로 이동했다 돌아오면 비교 화면은 유지됩니다.
- `node test-comparison.cjs`로 무작위 문제의 물리 계산, 채점, 복수 정답, 기록 저장·재열람, 날짜 변경, 저장소 실패 처리를 검사합니다. `node test-game.cjs`는 기존 게임과 세 번째 기능 전환 회귀 검사입니다. 이 검사는 브라우저 시각 검증을 대체하지 않습니다.

index.html을 Chrome 또는 Edge에서 열면 실행됩니다. 설치, 빌드, 인터넷 연결이 필요 없습니다. 권장 화면은 1280×800 이상입니다.

## 조작과 진행
- 아래 별을 좌우로 드래그합니다. 방향키는 0.05pc, Shift+방향키는 0.5pc씩 이동합니다.
- 목표 사진의 등급은 숨깁니다. 현재 사진의 빛무리와 광선을 목표와 비교하세요.
- 안내 후 총 5회, 매회 30초 동안 조절합니다. 가까이 맞춰도 조기 종료하지 않습니다.
- 새 목표의 0.65초 등장 연출은 제한 시간에서 제외합니다. 탭을 벗어나면 일시정지합니다.
- 시간이 끝나면 목표와 현재 겉보기 등급, 1,000점 만점 점수와 평가 등급을 공개합니다. 다음 관측은 직접 시작합니다.

## 평가
겉보기 등급 차이 Δm = abs(목표 m - 현재 m), 점수 = round(1000 × exp(-2 × Δm))입니다. 표시 반올림 전 등급으로 계산합니다. 같은 등급은 1,000점이며 어느 방향으로 차이가 나도 동일하게 평가합니다. 속도 보너스는 없습니다.
A+: 950 이상, A: 900 이상, B+: 800 이상, B: 650 이상, C: 500 이상, D: 500 미만입니다. 이 배지는 게임 평가이며 천문학적 분류가 아닙니다. 매 관측 완료 시 해당 점수를 즉시 저장합니다. 5회 종료 화면은 이번 탐사의 최고 점수를 보여주며, 평균 점수는 계산하거나 저장하지 않습니다.
점수 상승과 배지 등장 효과는 움직임 감소 설정에서 생략합니다.

## 물리와 표현
수광량은 10^(-0.4M) × (10/d)^2, 겉보기 등급은 m=M+5log10(d/10)으로 계산합니다. 소광은 고려하지 않습니다. 두 별의 절대 등급은 서로 다르고 한 관측 동안 일정합니다. 도달 가능한 B의 거리에서 목표를 역산합니다.
사진의 빛무리·광선은 고정 노출의 학습용 표현입니다. 아래 공간은 3차원 좌표의 곡면 메시를 Canvas 2D에 투영하는 모형으로, 별의 중심 크기는 일정하며 빛무리와 광선은 절대 등급 숫자가 작을수록 강합니다. 아래 별 자체의 밝기는 거리를 움직여도 유지됩니다. 관측자 지구의 크기는 고정이며, 곡면 패치는 사방으로 퍼지는 구형 빛 껍질의 일부입니다.

## 지구와 구형 껍질
관측자 위치의 지구는 별을 향한 면과 대기 빛무리가 실제 계산 수광량에 따라 밝아집니다. 화면 밝기는 보기 쉬운 범위로 압축합니다. 별과 지구 사이에는 별 중심의 동심 구면 패치 세 개를 거리비 1:2:3으로 표시하며 각각 1×1, 2×2, 3×3 격자로 같은 빛이 넓은 면적에 퍼지는 관계를 설명합니다. 부드러운 이동 껍질은 전파 방향을 보여주며 실제 광속의 시간 축척은 아닙니다. 일시정지 및 움직임 감소 설정에서는 이동을 멈춥니다.

빛 1·1/4·1/9 기준 껍질은 별에서 10·20·30pc의 고정 반지름을 사용합니다. 별을 드래그하면 껍질이 같은 크기로 함께 이동하며, 화면 밖으로 나간 부분은 잘립니다. 이동 껍질은 지구까지의 거리와 무관한 전파 범위를 사용합니다. 3차원 지구 구면과의 광선 교차로 충돌 위치를 구하고, 지구에 차단된 껍질 부분은 사라지고 빗나간 면은 계속 이동하며, 곡면 껍질의 각 방향에서 구면 충돌 여부를 계산해 차단된 부분을 제거합니다.

## 3차원 그림자
지구는 불투명 구면 메시이며 구형 껍질도 XYZ 좌표로 계산합니다. 카메라는 Y축으로 기울인 직교 투영을 사용합니다. 별을 점광원으로 보고 광선-구면 교차를 계산하므로 지구 뒤의 그림자 부피는 원뿔이고, 움직이는 구면 껍질과 만나는 경계는 곡면의 빈 영역입니다. 경계 메시를 세분화하며 깊이순으로 그립니다. 유한 크기 광원의 반그림자, 산란, 실측 지구 지형은 모델링하지 않습니다. 외부 라이브러리나 빌드는 필요 없습니다.

이동하는 점 형태의 빛 입자와 충돌 반짝임은 표시하지 않습니다. 빛의 전파는 곡면 껍질만으로 표현합니다.

빛 1·1/4·1/9 기준 면은 지구 구 내부에 들어간 곡면 부분만 제거합니다. 지구 뒤로 완전히 벗어나면 기준 면은 복원됩니다. 이동 빛 껍질은 기존처럼 흡수된 광선의 뒤쪽 영역도 차단합니다. 지구 자체가 앞에서 가리는 부분은 정상적인 깊이 가림을 유지합니다.

## 탐사 지역의 배경 별
사진 배경에 밝기·크기·색조가 다양한 별 130개를 무작위로 배치합니다. 목표와 현재 사진은 같은 배경을 공유합니다. 거리 조절, 관측 전환, 일시정지, 창 크기 변경으로 배경 데이터를 재생성하지 않으며, 새 게임의 준비 완료 버튼으로 실제 탐사를 시작할 때만 다시 배치합니다. 중앙 실험 별 주변은 비워 비교를 돕습니다. 배경 별은 깜빡이거나 이동하지 않습니다.

## 절대 등급 범위
도전의 매 관측마다 조절 별 B의 절대 등급을 -5.0~+5.0에서 0.1 단위(101개 값)로 균등 무작위 선택합니다. 목표 별 A도 같은 범위에서 B와 다른 값으로 선택합니다. B의 정답 거리를 먼저 정해 항상 5~30pc 안에서 풀 수 있습니다. 절대 등급은 소수점 한 자리, 겉보기 등급은 비교·평가를 위해 두 자리로 표시합니다. 도전 전에는 준비 화면만 표시하며 별 이동은 잠겨 있습니다. 사진에는 모든 관측에서 동일한 단조 증가 압축 곡선을 적용해 극단적인 밝기도 비교할 수 있게 하며, 물리 계산과 점수에는 원래 수광량·등급을 사용합니다.

관측 중 중앙 타이머 아래의 ‘별 이동 완료’를 누르면 현재 위치로 즉시 채점합니다. 등장 연출과 일시정지 중에는 비활성화되며, 30초 자동 제출도 유지됩니다. 조기 제출의 점수 보너스나 감점은 없습니다.

## 등급 맞추기 모드
상단에서 ‘사진 맞추기’ 또는 ‘등급 맞추기’를 선택합니다. 전환하면 진행 중 탐사는 종료되고 해당 모드의 도전 준비 화면으로 돌아갑니다.
등급 맞추기는 목표 겉보기 등급을 -5.0~+5.0에서 소수점 한 자리로 보여줍니다. 목표 사진은 보여주지 않습니다. 실제 절대 등급과 출발 위치를 함께 생성해 목표에 도달 가능한 거리를 6~29pc 안으로 보장합니다. 출발 겉보기 등급도 한 자리 값이며 내부 계산과 일치합니다.
도전 시작 후에는 첫 실제 이동 전까지 시간이 흐르지 않습니다. 첫 이동부터 30초이며 현재 겉보기 등급 표시는 ?로 바뀝니다. 원래 출발점을 통과하면 0.4초 동안 ‘출발 등급’으로 기준값을 표시하고 출발 위치에 링을 표시합니다. 출발 위치에 멈춰 있으면 계속 표시합니다. 이전/새 위치 사이의 부호 변화를 검사하므로 빠른 드래그로 건너뛰어도 감지합니다. 키보드 조절도 같은 규칙입니다.
수광량·절대 등급은 새 모드에서 숨기고, 현재 겉보기 등급은 사진 및 하단 정보판 모두 같은 표시 규칙을 사용합니다. ‘별 이동 완료’ 또는 시간 종료 후 최종 등급과 점수, 가까이/멀리 이동에 대한 한 문장 피드백을 제공합니다.

개발 검증: `node test-game.cjs`로 미션 도달 가능성, 출발점 복귀/통과, 타이머, 일시정지, 결과, 모드 전환을 검사할 수 있습니다. 브라우저 시각 검증과 별개의 로직 검사입니다.

## 원래 화면에서 결과 비교
매 관측 결과는 화면 중앙의 컴팩트한 반투명 패널에 점수·평가 배지·짧은 피드백을 표시합니다. 배경을 강하게 어둡게 하지 않고 원래 목표/현재 사진 영역에서 겉보기 등급을 공개·강조합니다. 사진 맞추기도 결과 때만 목표 숫자가 나타나고 다음 관측에서는 숨겨집니다. 화면 높이가 부족하면 결과 패널 내부를 스크롤합니다. 화면 읽기 프로그램을 위해 모달에는 두 등급의 텍스트 설명을 유지합니다.

안내 문장과 평균 점수가 있던 중간 상태 줄, 자유 탐사 버튼 및 기능을 제거했습니다. 도전 시작 전이나 모드 전환 후에는 준비 화면이며 별을 조절할 수 없습니다. 점수는 결과 패널에서만 확인합니다.

등급 맞추기의 출발 위치는 거리 눈금의 10 배수인 20pc로 고정합니다. 가까이/멀리 가는 목표 방향을 먼저 50% 확률로 선택한 후 도달 가능한 문제를 생성합니다. 출발·목표 겉보기 등급은 한 자리 값을 유지하며, 숨겨진 절대 등급은 고정 출발 거리에서 출발 등급이 정확하도록 역산합니다(-5~+5 범위). 출발 위치 자체가 정답 방향의 단서가 되지 않습니다.

매 관측 시작 시 조절 별 위에 흰색 아래쪽 화살표와 “Drag me!”를 표시합니다. 화살표와 문구는 첫 실제 이동까지 부드럽게 통통 튀며, 민트색 링은 고정 표시합니다. 이동 후에는 얇은 링만 남습니다. 별의 광도 표현은 바꾸지 않으며, 마우스·터치 잡기 영역은 중심 기준 가로 ±60px, 세로 ±65px입니다. 움직임 감소 설정에서는 화살표 애니메이션을 생략합니다.

결과 패널은 화면 중앙에 최대 너비 420px로 배치합니다. 점수·등급 배지와 버튼 간격을 줄이고 반투명 배경 및 뒤쪽 사진의 등급 강조를 유지합니다. 작은 화면에서는 화면 안쪽 여백을 확보하고 필요한 경우 패널 내부를 스크롤합니다.

브리핑의 ‘오늘은 그만 보기’ 체크는 모드별로 브라우저 localStorage에 기기의 현지 날짜를 저장합니다. 당일 재도전에서는 안내 없이 시작하며, 날짜가 바뀌면 다시 안내합니다. 저장소를 사용할 수 없는 환경에서는 현재 페이지 세션 안에서만 기억합니다.

## 오늘의 기록

사진·등급 맞추기의 저장 실패 점수는 별도 대기 목록에 보관해, 기록을 다시 열 때 이전 저장값으로 사라지지 않도록 합니다. 일시적인 읽기 오류에는 마지막으로 읽은 기록을 사용하며, 이후 도전을 완료해 저장에 성공하면 대기 점수도 함께 저장합니다. 기록 창에는 저장소 문제를 안내합니다. 페이지를 닫기 전까지 저장이 복구되지 않으면 대기 점수는 사라질 수 있습니다. 거리 퀴즈의 기록 조회 오류는 사진·등급 맞추기 기록 창을 막지 않습니다.
상단 버튼 묶음 오른쪽의 ‘오늘의 기록’에서 사진/등급 맞추기의 오늘 최고 점수와 평가 등급을 확인합니다. 기록은 각 관측의 개별 점수(1,000점 만점)이며 매 결과가 나오는 즉시 저장합니다. 중간에 종료하거나 모드를 바꿔도 완료한 관측 기록은 남습니다. 기기 현지 날짜와 함께 localStorage의 starlight.dailyRecords.v1에 보관하고 각 모드의 상위 5개 개별 점수를 유지하며 같은 점수도 별도 기록합니다. 날짜가 다르면 과거 점수를 표시하지 않으며, 모달이 열린 상태에서 날짜가 바뀌어도 갱신합니다. 진행 중 열면 일시정지하며 닫은 뒤 계속하기로 재개합니다. 저장소 접근 실패 시 현재 페이지에서만 보관하고 안내합니다.

거리 퀴즈 결과의 계산 표는 학생이 제출한 값을 그대로 보존하고 정답·판정·뺄셈식을 나란히 보여줍니다. 음수 빼기와 부호가 반대인 답을 설명하며, 계산값이 10 pc 안팎의 거리와 어떤 관계인지 해석합니다. 선택 문제는 빠뜨린 별과 잘못 고른 별, 기준값을 표시하고, 거리순 문제는 틀린 위치와 등급 차이의 오름차순을 설명합니다. 제출 직후와 오늘의 기록 재열람에 동일하게 적용됩니다.
